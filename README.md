# 🏦 Loan Approval Prediction System

### A Machine Learning Web App for Smart Loan Decisioning

A predictive **Loan Approval System** built using **Machine Learning**, evaluating applicant information to determine whether a loan should be **Approved** or **Rejected** — delivered through an interactive **Streamlit** web interface.  

---

## 📌 Project Overview

Accept applicant financial and demographic details such as income, credit history, and loan amount, and instantly predict **loan approval status**. Demonstrates a complete **end-to-end ML pipeline**, from preprocessing to real-time deployment.  

---

## ✨ Key Features

- Real-time loan approval predictions  
- Decision Tree–based classification model  
- Feature-engineered financial indicators (EMI, Total Income, Balance Income)  
- Interactive Streamlit web application  
- Automated preprocessing and encoding pipeline  
- Fast and consistent decision support  

---

## 🛠 Tech Stack

**Python** • **Pandas** • **NumPy** • **Scikit-learn** • **Streamlit** • **Pickle**  

---

## ⚙ How It Works

1. Loads trained ML model and preprocessing objects  
2. Accepts applicant details via Streamlit interface  
3. Applies encoding and aligns features with training data  
4. Computes derived financial metrics  
5. Predicts loan status using Decision Tree model  
6. Displays **Approved / Rejected** decision instantly
